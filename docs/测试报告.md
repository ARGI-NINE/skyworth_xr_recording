## 2. 200 轮回归结果

`auto_capture_verify.py` 的固定配置为：

```text
CYCLES = 200
RECORD_SECONDS = 120
AFTER_STOP_WAIT_SECONDS = 5
VERIFY_TIMEOUT_SECONDS = 60
```

每轮只有在以下条件全部满足时才计为 PASS：

- 新建 dataset 目录；
- 必需媒体、CSV、JSON 和日志文件存在且非空；
- 关键 CSV 至少包含一行数据且表头正确；
- `capture_status.json.state == "complete"`；
- dataset 路径与状态文件一致；
- `capture.log` 不包含 `[error]`。

已有 200 轮回归结论：

```text
total: 200
pass : 200
fail : 0
ALL PASS: 200 cycles all completed correctly
```

说明：本次功耗测试没有重新执行 200 轮回归；上面的结论对应 `auto_capture_verify.py` 的 200 轮回归测试记录。功耗测试只执行了四个约 5 分钟阶段。

## 3. RGB metainfo：驱动时间与应用时间差

本节使用 `build/auto_capture_200_audit/rgb_all/*/rgb_metainfo.csv`，不是 `capture.log`，也不是 callback 处理耗时。

每一帧按以下公式计算：

```text
差值_ms = (app_boottime_utc_ns - mid_exposure_utc_ns) / 1_000_000
```

其中 `mid_exposure_utc_ns` 是 RGB 驱动/相机帧的曝光中点时间，`app_boottime_utc_ns` 是应用层记录时间。先对每个 CSV 的全部帧求平均，再统计 200 次录制：

| 统计对象 | 结果 |
|---|---:|
| RGB metainfo CSV 数量 | 200 次 |
| RGB 总帧数 | 721043 帧 |
| 每次平均差值的平均值 | **34.063160 ms** |
| 每次平均差值最小值 | **33.903195 ms** |
| 每次平均差值最大值 | **34.341335 ms** |
| 200 次平均值标准差 | **0.078685 ms** |

每次录制的明细表已经记录在 [`rgb_app_driver_delta_200.csv`](../build/auto_capture_200_audit/rgb_app_driver_delta_200.csv)，其中 `app_boottime_minus_mid_exposure_mean_ms` 就是每次录制的 RGB metainfo 平均时间差。

## 4. 四阶段系统 CPU 结果

Android `top` 的多核结果已按总核数折算为系统整体百分比：

```text
system_cpu_used = 100 - idle_sum * 100 / total_cpu_capacity
```

| 阶段 | 实际时长 | 样本数 | 系统 CPU 平均 | 系统 CPU 最大 |
|---|---:|---:|---:|---:|
| Idle | 300 s | 62 | 38.88% | 43.50% |
| 只推流（PHONE_PREVIEW） | 302 s | 62 | 40.99% | 48.62% |
| 手机录制（PHONE_RECORD） | 300 s | 61 | 62.11% | 70.50% |
| 本机保存（LOCAL_RECORD） | 303 s | 57 | 61.34% | 66.12% |

### 4.1 四阶段耗电

耗电使用电池 `charge_counter` 的下降量计算；`mAh/h` 是按实际测试时长折算的耗电速率。电池百分比是整数显示，只作为辅助参考。

| 阶段 | charge counter 下降 | 折算耗电速率 | 电池百分比 |
|---|---:|---:|---:|
| Idle | 37.304 mAh | 447.648 mAh/h | 89% → 89%（0 个百分点） |
| 只推流（PHONE_PREVIEW） | 44.427 mAh | 529.593 mAh/h | 88% → 87%（1 个百分点） |
| 手机录制（PHONE_RECORD） | 87.036 mAh | 1044.432 mAh/h | 87% → 85%（2 个百分点） |
| 本机保存（LOCAL_RECORD） | 87.090 mAh | 1034.733 mAh/h | 79% → 77%（2 个百分点） |

前三个阶段使用各自的五分钟采样结果；本机保存行使用有状态测试结果。完整原始 CSV 和 `summary.txt` 保存在 `power_tests/` 对应目录中。
